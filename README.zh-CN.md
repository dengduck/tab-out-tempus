# Tab Out Tempus

**掌控你的标签页。**

Tab Out Tempus 是一个 Chrome 新标签页扩展，将所有打开的标签页按域名分组展示在一个简洁的仪表盘上。Homepages（Gmail、X、LinkedIn 等）自动归入专属分组。关闭标签时有动听的音效和彩纸特效。

无服务器。无账号。无外部请求。纯 Chrome 扩展。

## 功能特性

### 核心功能
- **一目了然的标签页展示** 干净的网格布局，按域名自动分组
- **Homepages 专属分组** Gmail 收件箱、X 首页、YouTube、LinkedIn、GitHub 首页集中到一张卡片
- **优雅地关闭标签** 配有 swoosh 音效 + 彩纸爆裂特效
- **重复标签检测** 同一页面打开多次时自动标记，一键去重
- **点击跳转任意标签** 跨窗口直达，不会打开新标签
- **稍后阅读** 关闭标签前先收藏到清单里
- **localhost 端口分组** 开发时每个项目端口清晰可辨
- **可折叠分组** 超过 8 个标签时显示 "+N 更多"
- **100% 本地** 数据绝不离开你的电脑
- **纯 Chrome 扩展** 无需服务器、Node.js、npm 或任何额外配置

### 时间与统计
- **会话时间追踪** 实时显示每个域名的浏览时长
- **域名计时徽章** 每张域名卡片上实时更新的计时器
- **历史统计** 在「今天 / 本周 / 本月 / 本年」之间切换，查看时间去向
- **隐私黑名单** 将特定域名排除在所有统计之外
- **生产力横幅** 在今天和本周视图顶部显示温暖鼓励的小结
- **24 小时热力图** 按域名可视化每日浏览强度（今天视图）
- **标签老化追踪** 超过 7 天未访问的域名显示徽章

### 专注与隐私
- **隐私模式（专注计时器）** 暂停所有时间追踪，可选时长（15 分钟 / 30 分钟 / 1 小时 / 2 小时 / 8 小时 / 到午夜）—— 处理敏感事务时不留痕迹
- **并发域名检测** 打开过多域名时提示你整合标签
- **标签休眠** 使用 Chrome 原生 Discard API 将闲置标签休眠以节省内存；一键唤醒（💤 徽章 + 灰色卡片）

### 数据与历史
- **批量导出历史** 将所有浏览统计下载为 JSON 文件备份
- **导入历史** 迁移或重装扩展时恢复统计数据

## 手动安装

**1. 克隆仓库**

```bash
git clone https://github.com/dengduck/tab-out-tempus.git
```

**2. 加载 Chrome 扩展**

1. 打开 Chrome，访问 `chrome://extensions`
2. 右上角开启**开发者模式**
3. 点击**加载已解压的扩展程序**
4. 选择克隆仓库中的 `extension/` 文件夹

**3. 打开新标签页**

你会看到 Tab Out Tempus。

## 工作原理

```
你打开一个新标签页
  → Tab Out Tempus 展示所有标签，按域名分组
  → Homepages（Gmail、X 等）在顶部独立成组
  → 点击任意标签标题直接跳转
  → 关闭不需要的分组（音效 + 彩纸）
  → 关闭前先保存标签到"稍后阅读"
  → 切换到 本周/本月/本年 查看浏览历史
  → 需要专注时开启隐私模式，暂停追踪
  → 休眠闲置标签节省内存，一键唤醒
  → 重装前导出历史，重装后导入恢复
```

一切运行在 Chrome 扩展内部。无外部服务器、无 API 调用、无数据外传。标签和浏览历史存储在 `chrome.storage.local`。

## 致谢

特别感谢 **[web-activity-time-tracker](https://github.com/brave-tools/web-activity-time-tracker)** —— 一个优秀的开源 Chrome 网页活动时间追踪扩展。Tab Out Tempus 与它**不共享任何代码**（技术栈完全不同：对方用 Vue/TypeScript，我们用原生 ES Module），但通过研究它的架构我们获得了宝贵的设计启发：

- `chrome.idle` API 的正确用法 + 对播放中音视频的豁免思路
- 限时 block 的极简实现路径（通过 `chrome.tabs.update` 跳转到本地 block 页面，零额外权限）
- 启发了我们的差异化方向 —— 对方做的是单域名限时，我们在此基础上延伸出**基于分类的组限额**（例如"娱乐"分类下多个网站共享一个每日预算）
- 通过对照其架构，帮助我们锁定了**单一时间账本**模型（见 `docs/DECISIONS-v2.md` D17）

感谢该项目坚持开源，让这种相互学习成为可能。
